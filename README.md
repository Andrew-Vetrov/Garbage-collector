# Garbage-collector

## Описание

Этот проект реализует многопоточный консервативный mark&sweep сборщик мусора для C программ. Сборщик поддерживает автоматическое управление памятью, работу с несколькими потоками и предоставляет инструменты для интеграции с пользовательским кодом.

## API

Публичное API состоит из трёх функций:
- `gc_malloc()`
- `gc_calloc()`
- `gc_realloc()`

## Быстрый старт

1. Клонируйте репозиторий:
   ```sh
   git clone https://github.com/Andrew-Vetrov/Garbage-collector.git
   cd Garbage-collector
   ```

2. Соберите проект:
   ```sh
   make
   ```

3. Соберите свою программу с библиотекой, подключив `gc.h`:
   ```sh
   gcc your_program.c ./build/libgc.so
   ```
